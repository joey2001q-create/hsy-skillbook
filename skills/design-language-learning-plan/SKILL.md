# 语言学习方案设计

## 工作流

1. 明确目标、当前表现、期限、每日或每周可用时间，以及是否有考试分数要求。信息不足时只询问会显著改变方案的问题；若用户要先看建议，明确假设后继续。
2. 按能力而非笼统的“基础差”诊断：声音识别、词汇与语法理解、实时提取、发音、互动、阅读、写作、考试策略。
3. 区分方法中的有效机制、未经证实的数字、适用条件和目标缺口。评价争议主张时加载 [证据边界](references/evidence-boundaries.md)。
4. 采用“理解声音 -> 情境绑定 -> 撤掉辅助 -> 直接理解 -> 有约束输出与反馈”的训练闭环。制定具体练法时加载 [核心方法](references/core-method.md)。
5. 同时覆盖意义输入、意义输出、语言聚焦学习和流利度训练；可按阶段偏重，不得永久删除任一条。
6. 若目标是雅思，加载 [雅思适配](references/ielts-adaptation.md)，按目标分数、单项短板和备考阶段分配四科，而不是把电影精听当完整备考。
7. 输出可执行计划，并给出复盘指标和调整规则。不要用播放器时长、刷过的电影数量或主观“有语感”作为唯一进度指标。

## 输出要求

- 先给判断：哪些观点值得采用，哪些需要修正，以及为什么。
- 再给方案：材料难度、单次步骤、频率、时间分配、反馈来源和阶段目标。
- 使用行为指标，例如陌生材料理解率、听错类型、限时回答完成度、写作错误复现率和模考单项变化。
- 区分通用语言能力与考试技能；短期冲刺与长期习得使用不同配比。
- 当用户只问一个具体问题时直接回答，不强行生成完整课程。

## 禁区

- 不把“90% 靠听”“1500 小时”“10 部电影”“快 5-10 倍”等数字写成科学阈值。
- 不建议长期完全停止口语或写作；反对的是无反馈、低质量的盲目输出。
- 不把完全听不懂的背景播放等额计入有效学习。
- 不把电影、剧集或任一单一材料称为唯一高效路径。
- 不以输入能促进输出为由，声称输入会自动产生准确、灵活的输出。
