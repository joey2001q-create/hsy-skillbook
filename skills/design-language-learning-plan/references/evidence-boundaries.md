# 证据边界

## 分析争议方法的框架

将每项主张拆成四层：

1. **可观察问题**：例如学习者认得拼写却无法从语流中识别。
2. **可能机制**：例如可理解输入、重复提取、撤掉辅助和情境线索促进声音自动化。
3. **教学建议**：例如前期增加听力比例、减少无反馈闲聊。
4. **强数字或排他结论**：例如固定百分比、固定小时数、唯一材料、保证提速。

前两层可以有道理，并不自动证明后两层。分别评价，不因博主个人成功、学生反馈或单段课堂即时进步而推出普遍因果结论。

## 常见过度推断

- “听力很重要”不能推出“所有人永久用 90% 时间听”。
- “可理解材料优于盲听”不能推出“任何没完全听懂的输入都无效”。
- “输入促进口语”不能推出“无需检索、互动和纠错，口语会自动准确”。
- “隐性学习能形成模式感”不能推出“成人永远不需要显性语法说明”。
- “电影情境丰富”不能推出“电影是唯一或对所有目标最优的材料”。
- “熟悉材料进步明显”不能证明能力已迁移到陌生材料。
- 个人经历、课程展示和学员证言不能单独证明固定小时阈值或数倍效率优势。

## 更严谨的措辞

优先使用：

- “方向合理，但数字缺乏可核验依据。”
- “对这一类瓶颈有效，不等于构成完整方案。”
- “可以作为阶段性配比，不应当作永久公式。”
- “先做小规模试验，用迁移任务和阶段测评决定是否继续。”

避免使用：

- “科学证明只要……”
- “母语习得完全不需要……”
- “坚持某个小时数必然达到……”
- “不练某项能力也会自然满分……”

## 验证一个学习法

设计 2-4 周试验，固定总学习时间，记录训练内容和基线。结尾用未练过但同体裁、同难度的材料测试，并观察目标任务是否改善。若目标是考试，以标准化模考和评分反馈为主；若目标是交流，以陌生话题理解、限时表达和互动修复能力为主。

不要只用熟悉台词复现、连续打卡天数、播放时长或主观兴奋感判断成效。
