# 核心方法

## 适用问题

这套闭环主要解决“文字认识，真实语流听不出来”和“理解知识多，实时调用慢”。它是一种声音自动化训练方法，不是完整语言课程的替代品。

## 单段材料训练闭环

1. **基线盲听**：先听一次，只记录主题、已听出的内容和卡点，不急着看答案。
2. **文字解码**：对照可靠文本，确认词义、搭配、词序、句法、连读弱读、重音和说话意图。
3. **声音与情境绑定**：把语音和人物、动作、场景、意图联系起来，避免只记“英文拼写 = 中文释义”。
4. **分句直接理解**：重复困难片段，直到不逐词翻译也能理解。按达标情况停止，不机械规定次数。
5. **逐步撤架**：从英文文本加画面，过渡到无文本画面，再到纯音频。若撤架后失败，返回具体卡点，不整段盲刷。
6. **间隔复测**：第二天及一周后改变片段顺序复听，检查记住的是语言还是剧情位置。
7. **迁移验证**：听同主题、相近难度的新材料。熟悉片段听懂不等于能力已经迁移。
8. **有约束输出**：复述、替换角色或信息、限时回答相关问题，再通过老师、语伴或可靠工具纠正。

## 选材

- 材料应有可靠文本，主题大体可理解，并略高于当前水平。
- A1-A2 优先分级音频、短情景对话和清晰慢速材料；不要从整部原声电影起步。
- B1-B2 可用 1-3 分钟剧集片段、访谈、科普、播客和考试材料混合训练。
- 电影擅长提供日常语音、语用和情境；学术、职场或考试目标必须补齐相应体裁。

## 有效学习判断

一次练习应满足多数条件：注意力在内容上；大意可理解；能定位没听出的声音；复听后能修正；隔天仍能理解；能复述主要内容；对新片段出现迁移。

背景播放可以增加接触感，但完全不理解、没有注意和修正的时长不能与上述训练等额统计。

## 输出时机

初期让输入多于自由输出是合理的，但从一开始即可使用短小、有约束的输出：模仿、跟读、替换、复述和准备后回答。随着语言库存增长，逐步增加即兴互动。输出的作用是暴露缺口、训练提取并获得反馈，不只是展示已有能力。

## 四条学习线

长期方案同时包含：

- 意义输入：听和读能够理解的内容。
- 意义输出：说和写真实信息。
- 语言聚焦：词汇、发音、语法与错误纠正。
- 流利度：用已掌握材料提高处理速度。

不必每天绝对均分，但每个训练周期都要覆盖四条线。
